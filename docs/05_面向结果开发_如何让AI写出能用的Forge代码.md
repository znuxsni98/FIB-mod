# 05. 面向结果开发：如何让 AI 帮你写出不翻车的 Forge 模组代码

如果你不是专职 Java 程序员，而是“面向结果编程”（用 AI 辅助写代码、自己组装整合包玩法），这是目前非常高效的做法！

但你之前一定遇到过这种痛苦：
* AI 给了一段代码，贴进去满屏红字，报一堆 `无法解析符号`；
* AI 嘴里说的头头是道，结果方法根本不存在；
* 贴了代码之后，自己不知道该怎么跟队友解释。

只要掌握以下几个核心技巧，AI 就会从“制造报错的坑货”变成“神级辅助”。

---

## 一、AI 为什么老是坑你？（三大死因）

### 1. 致命死因一：版本穿越（AI 给你写了高版本代码）
* **现状**：ChatGPT / Claude 训练数据里有海量 Minecraft 1.20.6 和 1.21 的代码。而 1.20.5+ 是原版底层代码最大的一次大改版。
* **表现**：AI 可能会给你用 `DataComponents` 代替 `NBT`，或者给一个 1.20.1 根本没有的泛型。你一编译，直接报几十个红字。

### 2. 致命死因二：AI 漏给关联文件（“只给枪，不给子弹”）
* **之前 IceBall 报错的真相**：
  你让 AI 帮你写冰球，AI 给你写了 `ModEntities.java` 和 `IceBallItem.java`。在代码里写了 `new IceBall(level, player)`。
  但 AI 那一次回答因为字数限制或者偷懒，**把 `IceBall.java` 本身漏掉了**！
  你只复制了物品类，没复制冰球实体类，IDEA 当然直接红字报错 `无法解析符号 'IceBall'`。

### 3. 致命死因三：Core Shader 忘记要源文件
* **之前 Shader 报错的真相**：
  AI 给了一个 `dimensional_crack.json`，在里面声明了 `"vertex": "fib_mod:dimensional_crack"`。
  如果你没向 AI 索要 `.vsh` 和 `.fsh`，游戏启动时找不到底层着色器，就会报 `IOException` 崩溃。

---

## 二、向 AI 提需求的【万能防护咒语】（直接复制）

以后每次在 ChatGPT / Claude / Gemini 里问问题，**开头第一句话必须复制这段文字**：

> 📌 **复制这段话作为你的提问开头**：
> 
> ```markdown
> 我正在开发 Minecraft 1.20.1 Forge 模组（Minecraft: 1.20.1, Forge: 47.4.20, Java 17, 官方 Official Mappings）。
> 【极其重要的规则】：
> 1. 严禁提供 1.20.5+ / 1.20.6 / 1.21 的任何代码！禁止使用 DataComponents，必须使用 1.20.1 的 CompoundTag 与 NBT API。
> 2. 如果你的代码里引用了任何新的自定义类（如实体类、渲染器、数据包），请必须在同一个回答中把这些类的完整 Java 源码全部写出来，严禁留空或只写一半！
> 3. 如果需要资源文件（如 JSON 模型、贴图路径、Core Shader 的 .vsh 和 .fsh），请必须提供完整的文本和精确的存放文件路径。
> 4. 所有代码必须能在 Forge 47.4.20 上直接通过 javac 编译！
> ```

只要你把这段咒语放在开头，AI 就绝不敢拿高版本代码忽悠你，也不会漏掉子类。

---

## 三、拿到 AI 代码后的【三秒安全检查法】

代码粘到 IDEA 之后，做这三件事：

1. **按一下快捷键看有没有红字**：
   * 在 IDEA 里按 `Ctrl + Shift + F9`（或者点击顶部菜单 Build -> Build Project）。
   * 如果有红字，看看是不是红在某个类名上。如果是，立刻把报错丢回给 AI：“你刚才的代码里缺少了 `xxx` 类的定义，请立刻给出该类的完整 1.20.1 代码。”

2. **在终端敲命令测试**：
   在 IDEA 底部的 Terminal 终端敲：
   ```bash
   ./gradlew compileJava
   ```
   只要看到绿色的 **`BUILD SUCCESSFUL`**，说明代码 100% 语法正确，没有漏任何文件！

3. **检查 Git 状态**：
   在终端敲：
   ```bash
   git status
   ```
   看看所有新建的文件是不是都在待提交列表里，然后：
   ```bash
   git add .
   git commit -m "添加了某某功能，本地 compileJava 测试已通过"
   git push
   ```
   这样队友拉下来永远不会炸，你们的对接也会无比丝滑！
